# CampusPilot 校园活动策划 Agent：MVP 约定

## 一句话目标

用户只输入一句自然语言目标，例如：

> 帮我策划一场2026年9月20日在苏州举行、50人参加、预算2000元的校园AI技术分享会。

Agent 自己提取约束、规划任务、调用能力、检查结果并输出完整策划书。

## 第一版范围

第一版最终需要完成以下闭环：

1. 提取活动名称、日期、城市、人数和预算。
2. 缺失或无效信息进入“待确认项”，不得猜测为事实。
3. 自动生成不少于 3 项、依赖关系明确的执行计划。
4. 检索校园规则，查询天气，匹配场地并计算预算。
5. 生成流程、人员分工、宣传材料和风险预案。
6. 检查规则冲突、预算超支、时间冲突和内容缺失。
7. 检查不通过时修订，最终输出一份完整策划书。

## 非目标

第一版不自动预约真实场地、不自动付款，也不自动向真实群聊发布消息。需要改变外部状态的动作只生成建议和待办，避免误操作。

## 分阶段验收

### 阶段 1：目标解析和任务规划

- 完整示例可以提取日期、城市、人数和预算。
- 未提供的字段保持为空并列入待确认项。
- 非法日期等输入产生明确校验问题，不导致程序崩溃。
- 规划结果至少包含 3 个任务，任务 ID 唯一且依赖项有效。

### 阶段 2：RAG 和工具

- 校园规则结论带知识库来源。
- 天气不可查询或日期太远时明确说明限制，并生成备用方案。
- 预算计算使用确定性代码，所有费用之和不得超过总预算。

### 阶段 3：执行闭环和成品

- 执行记录能够区分成功、失败、跳过和待确认状态。
- Evaluator 能发现预算超支、关键章节缺失和依赖失败。
- 最终输出包含事实、假设、待确认项、引用和完整策划内容。
